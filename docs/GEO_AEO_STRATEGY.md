# GEO / AEO Strategy

## Definitions (working)

- **AEO (Answer Engine Optimization):** structure content so AI/answer surfaces can cite clear, direct answers to real questions.
- **GEO (Generative Engine Optimization):** strengthen entity clarity, topical depth, authority, and citation-worthiness in generative answers — not keyword stuffing.

## What we optimize for

- Original insights and clear answers
- Authoritative claims with evidence
- Named entities and consistent terminology
- Structured information (Q&A, definitions, frameworks)
- Topical depth and interconnected clusters
- First-hand / tenant-specific expertise

## What we do not do

- Keyword stuffing
- Generic AI filler optimized only for length
- Claiming expertise the tenant does not have

## System support

- Entity/topic graph (light) for relationship awareness
- AEO generation: question → direct answer → supporting evidence → related entities
- Editorial checks for answer clarity, entity consistency, claim restraint
- Content packages that build clusters over one-off posts

## MVP

Generate AEO question sets from an opportunity; run editorial/GEO checklist as structured LLM output + rules. Full AI-visibility tracking is later (roadmap).
