# Roadmap

## Phase 0 — Foundation (current)

- Repository, AGENTS.md, docs
- Domain TypeScript models & interfaces
- LLM abstraction + Claude skeleton + stubs
- Conceptual schema (multi-tenant)
- Prompt folder stubs
- Workflow type definitions
- GitHub remote connected

**Not in Phase 0:** UI product features, live Claude feature flows, external collectors, publishing.

## Phase 1 — MVP vertical slice

1. Load tenant knowledge (seed Kona Kai)
2. Store POVs
3. Manual signal intake
4. Analyze signal via Claude + Intelligence Layer
5. Relevance + audiences + POV retrieval
6. Content opportunity + score
7. LinkedIn draft + AEO questions + GEO/editorial analysis
8. Human approval UI (minimal)

## Phase 2 — Editorial & knowledge depth

- Document upload + chunking + embeddings
- Stronger editorial rules engine
- Content package expansion (article outline, FAQ pages)
- Approval workflow polish

## Phase 3 — Signal automation

- Authorized collectors / APIs / RSS
- Dedup, scheduling, source health
- Still human-approved publishing

## Phase 4 — Distribution & learning

- LinkedIn / CMS publishing integrations
- Performance events & learning loop metrics
- AI visibility / authority dashboards
- Multi-brand / multi-executive UX

## Phase 5 — Platform

- Additional LLM providers / open-weight options
- Autonomous planning (optional, gated)
- Broader SaaS packaging
